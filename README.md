# 🏏 Rohit Sharma: Career Statistics & Insights Dashboard

A dynamic, interactive data visualization tool built to explore the legendary international cricket career of Rohit Sharma—focusing on format-based comparisons, run scoring trends, milestones, century analysis, and opponent-wise performance.

---

## 2. Short Description / Purpose

The **Rohit Sharma Career Stats Dashboard** is a visually engaging and analytical Power BI report designed to help cricket enthusiasts, sports analysts, and fans explore and analyze Rohit Sharma's performance data across all formats (ODI, T20I, and Tests). The dashboard focuses on highlighting key performance metrics like his year-by-year run progression, strike rates, dual-century trends, and visual breakups of matches won versus lost. This tool is intended for use by sports data analysts, cricket journalists, and strategy teams seeking to understand the impact and statistical mastery of one of cricket's modern greats.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Main data visualization platform used for report creation and canvas design.
* 📂 **Power Query** – Data transformation and cleaning layer used for reshaping, handling missing values, and preparing the cricket datasets.
* 📈 **DAX (Data Analysis Expressions)** – Used for calculated measures (e.g., cumulative runs, moving batting averages, strike rates) and advanced conditional logic.
* 🗂️ **Data Modeling** – Star schema relationships established among tables (Match_Stats, Format_Dim, Opponent_Dim, and Calendar_Dim) to enable seamless cross-filtering and deep-dive slicing.
* ---

## 4. Data Source

The data used for this dashboard is sourced from comprehensive international cricket archives (such as ESPN Cricinfo / Kaggle cricket datasets). 

It contains detailed match-by-match records of Rohit Sharma's career spanning from his debut to the present across Tests, ODIs, and T20Is. The dataset includes granular attributes such as runs scored, balls faced, strike rates, boundaries (4s and 6s), dismissal types, opponents, match venues, and match outcomes (Won/Lost/Drawn).

---

## 5. Features / Highlights

### 🎯 Business Problem & Goal
While raw cricket statistics are widely available, evaluating a player's long-term impact, consistency across varying formats, and performance under winning versus losing conditions requires deep visual synthesis. The goal of this dashboard is to transform traditional tabular cricket records into an interactive story that highlights Rohit Sharma's career evolution, milestone distributions, and situational match-winning capabilities.

### 🔍 Key Dashboard Features & Visuals
* **Career Overview Ribbon:** High-level KPI cards displaying aggregate career metrics—Total Runs, Hundreds, Half-Centuries, and overall Batting Average segregated by format.
* **Format-Wise Performance Analysis:** Comparative multi-line and bar charts tracking run progression, strike rates, and averages over time across Test, ODI, and T20 international formats.
* **Opponent & Venue Breakdown:** Dynamic matrix and map visuals that highlight which international teams and hosting countries have been his most successful hunting grounds.
* **Milestone & Century Tracker:** An interactive deep-dive visual isolating his landmark innings, including his historic ODI double centuries, analyzing scoring acceleration patterns.
* **The "Match Winner" Impact Split:** A visual comparison displaying performance metrics explicitly filtered by match outcomes, showcasing his statistical contribution in India's victories.
